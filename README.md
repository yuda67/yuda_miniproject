# PROGRAM PENCATATAN TABUNGAN

program ini bertujuan untuk mencatat setiap tabungan yang di masukan berdasarkan user, dan bersifat dinamis bisa berubah ubah, dan memiliki riwayat transaksi

# fitur
pembuatan akun 
login akun/masuk akun
logout akun
menambah uang tabungan sesuai yang diinginkan
menarik uang tabungan
melihat sisa uang tabungan
melihat riwayat transaksi menambah/menarik tabungan


# alur program
// sisi user
1.  login/regist akun
2.  masukan tabungan sesuai nominal yang dimana data login dari id dan nama akun tadi tersimpan di suatu variabel
    yang nanti akan ditambahkan ke data transaksi dan data tabungan user tersebut
